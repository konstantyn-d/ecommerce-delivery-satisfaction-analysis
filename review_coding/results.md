## 5. Consistency check (second coding pass)

30 of the 300 reviews, selected by hash and presented in a different order (`recode_set.csv`), were coded a second time with the codebook. The table compares the primary category of both passes.

| measure | value |
|---|---|
| Reviews coded twice | 30 |
| Same primary category in both passes | 30 (100%) |
| Cohen's kappa | 1.00 |

How to read this: both passes were made by the same coder with the same codebook, shortly after each other. The check shows that the rules are applied consistently. It is not an independent validation: a second coder could draw the lines between categories differently.
